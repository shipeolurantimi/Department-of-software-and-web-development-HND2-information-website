
# Department of Software and Web Development Information Website

## Project Overview

The Department of Software and Web Development Information Website is a web-based platform designed to provide students, prospective students, and visitors with important information about the Department of Software and Web Development.

The website serves as an online information center where users can learn about the department, its academic programmes, courses, lecturers, admission requirements, and other relevant departmental activities.

The project aims to improve access to departmental information and make communication between the department and students easier.

## Project Objectives

The objectives of this project are to:

- Provide important information about the department.
- Introduce prospective students to the Software and Web Development programme.
- Display departmental courses and academic programmes.
- Provide information about lecturers and staff.
- Make departmental information easily accessible online.
- Improve communication and information sharing.

## Features

- Departmental homepage
- About the department section
- Academic programmes information
- Course information
- Staff and lecturer information
- Admission requirements
- Contact information
- User-friendly navigation
- Responsive website design

## Technologies Used

The project was developed using:

- **HTML5** – for structuring the website.
- **CSS3** – for styling and designing the website.
- **JavaScript** – for interactive features and functionality.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in a web browser.
4. Navigate through the website to view departmental information.
